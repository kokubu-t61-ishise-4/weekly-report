# Activity Tracker

## 概要
週報・月報作成のための活動記録ツールです。
日々の業務活動をカテゴリ別に記録し、週報・月報形式のレポートを自動生成できます。
工数管理表からの一括登録にも対応しており、効率的に活動履歴を管理できます。

## 主な機能
- 活動の個別登録: 日付・カテゴリ・タイトル・詳細を入力して1件ずつ記録
- 一括登録: 工数管理表から作業内容をまとめてコピペで登録（工程コードからカテゴリ自動判定）
- カテゴリ分類: ミーティング、開発、調査、ドキュメント、レビュー、学習、サポート、運用、その他の9カテゴリ
- 活動一覧・編集: 期間・カテゴリでフィルタリング、詳細未入力の活動に後から追記可能
- レポート生成: 週報・月報形式でカテゴリ別にサマリーを自動生成、テキストファイルとしてダウンロード
- データ管理: JSON形式でエクスポート・インポート（バックアップ・復元）

## 使い方
1. サイドバーの「活動を記録」から日々の活動を登録
2. 1件ずつ登録、または工数管理表からの一括登録を選択
3. 「活動一覧」で登録済みの活動を確認・編集
4. 詳細未入力の活動には思い出しヒントが表示されるので後から追記
5. 「レポート生成」で週報または月報を自動生成
6. 「データ管理」でJSONバックアップを保存・復元

## 技術スタック
- **言語**: Python
- **フレームワーク**: Streamlit
- **データベース**: SQLite（ローカル保存）
- **ホスティング**: Streamlit Cloud
